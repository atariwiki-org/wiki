# Extreme Memory 512 MB (reported by HIAS) 

## - Description

Dieser Eintrag stammt direkt aus der Atari USB-Kompatibilitätsmatrix des AtariWiki und wurde von Matthias „Hiassoft“ Reichl (HIAS) getestet.
Im Gegensatz zu Ihrem ersten Gerät zeigt dieser Eintrag jedoch ein Kompatibilitätsproblem auf:

* Extreme Memory 512MB: Ein USB-Stick des Herstellers „Extreme Memory“ mit 512 Megabyte Speicherkapazität.
* sometimes working (manchmal funktionierend): Das Laufwerk ist nicht zuverlässig. Es wird vom Atari-USB-Interface (z. B. der USB-Cart) mal erkannt und mal nicht. Oft liegt das bei älteren oder günstigen USB-Sticks an ungenauem Timing bei der Signalübertragung oder an einer zu hohen Stromaufnahme beim Starten.
* DeviceDescriptors: Die Identifikation im System erfolgte auch hier über die Standard-USB-Gerätedeskriptoren. [1, 2, 3] 

Für den produktiven Einsatz am Atari (z. B. zum Laden von Spielen oder Speichern von Daten) ist dieses Modell aufgrund der Instabilität nicht zu empfehlen.
