# SpartDOS X

From [SpartaDOS X](https://en.wikipedia.org/wiki/SpartaDOS_X).

SpartaDOS X (or SpartaDOS 4.0) is a disk operating system for the Atari 8-bit computers that closely resembles MS-DOS. It was developed and sold by [ICD](../README.md) in 1987-1993, and many years later picked up by the third-party community [SpartaDOS X Upgrade Project](https://sdx.atari8.info/index.php), which still maintains the software.
